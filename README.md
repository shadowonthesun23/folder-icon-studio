# Folder Icon Studio

Create beautiful custom folder icons directly in your browser.

**Folder Icon Studio** is a small web app for designing personalized folder icons for macOS, projects, archives, workspaces and creative collections. Upload an image, choose a style, customize colors and labels, then export your icon as PNG, ICNS or ICO.

## Try it

👉 **Live demo:** https://folder-icon-studio.vercel.app/

## Features

- Create custom macOS-style folder icons
- Upload or drag and drop your own artwork
- Choose between folder and cassette-inspired styles
- Customize folder and cassette colors
- Add labels in different styles:
  - Dymo
  - Banner
  - Badge
- Adjust image zoom and rotation
- Move labels directly on the preview
- Save reusable visual presets
- Undo and redo changes
- Export as:
  - PNG 1024×1024
  - ICNS for macOS
  - ICO for Windows
- Available in English and Italian

## Why I built it

I wanted a quick and visual way to make project folders feel more personal without opening a full design app every time.

Folder Icon Studio is useful for developers, designers, students, collectors, archivists or anyone who likes having a cleaner and more recognizable desktop or workspace.

## How to use

1. Open the app.
2. Upload an image.
3. Choose a folder style.
4. Adjust color, zoom and rotation.
5. Add a label if needed.
6. Export the final icon.

## Local development

Clone the repository:

```bash
git clone https://github.com/shadowonthesun23/folder-icon-studio.git
cd folder-icon-studio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
